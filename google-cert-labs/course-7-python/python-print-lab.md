## Summary

This lab introduced me to writing and running Python code in a notebook environment. I learned how to use markdown cells for documentation, write code comments to explain my logic, and display output using the `print()` function. I also practiced combining multiple print statements into a single code cell.

## Key Takeaways

- **Comments are ignored by Python** – they are only for human readers.
- **`print()` displays output** – it automatically adds a newline after each message.
- **Notebooks combine text and code** – markdown cells for explanations, code cells for execution.
- **Print statements can be combined** – multiple `print()` calls run in sequence.

## Code Example

```python
# This cell displays multiple statements about my learning journey

print("Completing Google Cybersecurity Professional: Automation with Python")
print("I'm writing a portfolio on GitHub")
print("I am a security analyst currently completing the Google Certs on Coursera")
print("Python is useful for cybersecurity field")
```
