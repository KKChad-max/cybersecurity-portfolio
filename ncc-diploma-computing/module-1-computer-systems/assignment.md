## Overview

This assignment analysed the hardware, software, networking, and future computing opportunities for **QuantumTech**, a bespoke computer manufacturer serving technology start-ups. The report covered four key areas:

1. **Hardware & Operating Systems** – CPU, Storage, RAM, and OS functionalities.
2. **Software Bundling** – Application, system, and development software categories.
3. **Networking** – LAN/WAN/MAN configurations, topologies, and the OSI model.
4. **Future Computing** – Distributed and quantum computing for start-ups.

### Software Execution & Interfaces

**How Software Runs:**
1. Source code is compiled into machine code.
2. Program is loaded into RAM.
3. CPU executes instructions.
4. Software interacts with devices via APIs, drivers, and system calls.

**Interfaces:**
- **API:** Pre-defined functions for hardware access.
- **Device Drivers:** Manage hardware interactions.
- **Interrupts:** Hardware signals triggering software responses.
- **System Calls:** Software requests for OS services.

## Task 3: Networking

### Network Configurations

| Type | Purpose | Key Characteristics |
| :--- | :--- | :--- |
| **LAN** | Connect devices in a building. | High speed (10 Gbps), low latency, limited range. |
| **MAN** | Connect devices across a city. | High speed, lower latency than WAN, medium range. |
| **WAN** | Connect devices across countries. | Lower speed (100 Mbps), higher latency, global range. |

**Recommendation for QuantumTech:** Start with **LAN** for start-ups – cost-effective, fast, and easy to maintain.

---

### LAN Topologies

| Topology | Reliability | Scalability | Maintenance | Best For |
| :--- | :--- | :--- | :--- | :--- |
| **Star** | Medium | High | Easy | Small to medium networks. |
| **Tree** | Medium | High | Medium | Hierarchical expansion. |
| **Mesh** | High | High | Complex | High-reliability environments. |
| **Hybrid** | High | High | Complex | Large, flexible networks. |

**Recommendation:** **Star topology** for simplicity and scalability.

---

### OSI Model for Communication

The **OSI Model** ensures consistent device communication across networks through 7 layers:

| Layer | Function |
| :--- | :--- |
| **7 – Application** | User-facing apps (HTTP, FTP, email). |
| **6 – Presentation** | Data formatting, encryption, compression. |
| **5 – Session** | Connection management. |
| **4 – Transport** | Reliable data transfer (TCP, UDP). |
| **3 – Network** | Routing using IP addresses. |
| **2 – Data Link** | Error-free frame transfer. |
| **1 – Physical** | Physical transmission (Ethernet, Wi-Fi). |

**How It Works:** Data moves down the layers, adding headers, then up the receiving device, removing headers.

## Task 4: Future Computing

### Distributed Computing

**Definition:** Multiple networked computers collaborating to achieve a common goal, creating a virtual supercomputer.

**Client-Server vs. Peer-to-Peer:**

| Model | Description |
| :--- | :--- |
| **Client-Server** | Centralised server provides services to clients. |
| **Peer-to-Peer** | Equal nodes share resources without central control. |

**Core Characteristics & Benefits for Start-Ups:**

| Characteristic | Benefit |
| :--- | :--- |
| **Concurrency** | Faster processing through parallel tasks. |
| **Scalability** | Easily add/remove resources as needed. |
| **Fault Tolerance** | No single point of failure. |
| **Transparency** | Users see a single, unified resource. |

---

### Quantum Computing

**Definition:** Uses quantum-mechanical phenomena (superposition, entanglement) to perform computations beyond classical capabilities.

**Advantages over Conventional Computing:**

| Advantage | Description |
| :--- | :--- |
| **Speed** | Exponential speed-up for specific problems (e.g., factoring large numbers). |
| **Parallel Computing** | Simultaneous exploration of multiple solution spaces. |
| **Optimisation** | Superior for ML model training and cryptography key generation. |

**Quantum Computing for Cryptography:**

- Enhanced key generation.
- Improved encryption (quantum-resistant algorithms).
- Potential to break RSA – driving need for new security standards.

**Implementation Considerations:**
- Partner with quantum providers (e.g., IBM Quantum).
- Develop hybrid classical-quantum solutions.
- Build expertise in quantum software.
